# Магазин клубной формы «СКАЗКА»

Мобильный одностраничный интернет-магазин спортивного клуба эстетической гимнастики «СКАЗКА».
HTML + CSS + Vanilla JS, заказы записываются в Google Таблицу «Форма заявки» через Google Apps Script.
Техническое задание: [TZ.md](TZ.md).

## Структура

```
index.html
css/style.css
js/data.js        — каталог (13 товаров), филиалы, API_URL, POLICY_URL
js/storage.js     — безопасная работа с localStorage
js/cart.js        — корзина
js/form.js        — форма заказа, маска телефона, отправка
js/app.js         — рендер каталога и корзины, окно подтверждения
images/           — logo.png, 1.jpg … 13.jpg, placeholder.svg
apps-script/Code.gs — серверная часть (Google Apps Script)
tools/prepare_images.py — подготовка картинок из папки Google Drive
```

## Запуск

1. **Картинки.** Скачайте папку с Google Drive и выполните:
   ```
   pip install Pillow
   python3 tools/prepare_images.py "путь/к/скачанной/папке"
   ```
   Появятся `images/1.jpg … 13.jpg` и `images/logo.png`. Пока картинок нет, на сайте показывается заглушка.
2. **Apps Script.** Откройте таблицу «Форма заявки» → «Расширения → Apps Script», вставьте содержимое `apps-script/Code.gs`.
   В настройках проекта укажите часовой пояс `Asia/Yekaterinburg` (Уфа, GMT+5).
3. Один раз запустите функцию **`setup()`** (выбрать `setup` → «Выполнить», подтвердить доступ):
   она выставит таблице часовой пояс Уфы и добавит заголовок «Сумма» в I1.
4. «Развернуть → Новое развертывание → Веб-приложение»: *Выполнять от имени* — **Я**, *Доступ* — **Все**.
   Скопируйте URL вида `https://script.google.com/macros/s/…/exec` в `API_URL` в `js/data.js`.
5. Разместите файлы на любом статическом хостинге с HTTPS (GitHub Pages, хостинг клуба).
   Локально: `python3 -m http.server` и открыть http://localhost:8000.

После изменения `Code.gs` выпускайте новую версию в том же развертывании
(«Управление развертываниями → Изменить → Новая версия»), чтобы URL не менялся.

## Таблица заявок

Лист «Лист1», одна строка — одна позиция заказа. Порядок колонок менять нельзя:

| A | B | C | D | E | F | G | H | I |
|---|---|---|---|---|---|---|---|---|
| Дата | Филиал | ФИ ребенка | Наименование товара | Размер | Кол-во | Цена | Номер телефона родителя | Сумма |

## Изменение цен и товаров

Цены, названия и размеры правятся в двух местах одинаково: `js/data.js` (`PRODUCTS`) и `apps-script/Code.gs` (`CATALOG`).
В таблицу всегда записываются цены из `Code.gs`.

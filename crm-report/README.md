# Отчёт по спортсменам из CRM

Скрипт Google Apps Script. Он собирает из SportCRM (skazka.start123.ru) ежемесячный отчёт в структуре
ручного отчёта менеджеров и помечает подозрительные строки в колонке «Флаги».

> Статус: первая версия. Она написана по документации API (OpenAPI 0.0.2) и проверена только на тестовых
> данных, на живой CRM её ещё не запускали. Места с предположениями помечены в коде словом `ПРОВЕРИТЬ`.

## Как работает

1. Менеджеры работают только в CRM.
2. Отчёт собирается по меню «CRM-отчёт → Собрать отчёт за месяц…» или каждый день автоматически.
   Результат появляется на листе «Отчёт ГГГГ-ММ».
3. Менеджеры смотрят флаги и исправляют ошибки **в CRM**, а не в таблице. Потом отчёт пересобирается.
   Если флаг стоит, но всё верно, это отмечают в колонках «Проверено» и «Комментарий».
   Эти колонки сохраняются при пересборке.
4. В конце месяца нажмите «Закрыть месяц…». Скрипт создаст лист «Итог ГГГГ-ММ»: это зафиксированная копия
   для расчёта зарплаты тренерам.

## Установка

1. Создайте Google Таблицу «Отчёт CRM», откройте «Расширения → Apps Script» и вставьте `Code.gs`.
2. В настройках проекта укажите часовой пояс `Asia/Yekaterinburg`.
3. Обновите таблицу. Появится меню «CRM-отчёт». Выберите «Ввести ключ API» и вставьте ключ из
   «Настройки CRM → API». Ключ хранится в свойствах скрипта, а не в коде.
4. Запустите «CRM-отчёт → Проверка API». На листе «Тест API» появятся реальные поля и значения статусов.
   По ним уточните настройки `CFG` в начале `Code.gs`:
   - `ATTENDED_STATUSES`: какой статус посещения означает «был на занятии» (предположительно `y`);
   - `TRIAL_STATUS`: отдельный статус пробного занятия, если он есть;
   - номер заказа (`numpay`?) и филиал (зал `idClub` или филиал `idCity`).
5. Если нужно, включите «Включить ежедневную пересборку текущего месяца».

## Правило для новичков

- Первое посещение — пробное, оно бесплатное и не считается.
- Дата старта — первое посещение после пробного.
- Ожидаемая выручка за первый месяц = цена тарифа ÷ занятий в месяц × число занятий группы по расписанию
  с даты старта до конца месяца, включая день старта. Пропуски после старта не учитываются.
  Отменённые занятия (`cancel`) не считаются. Сумма не может быть больше цены тарифа.
- Число занятий в месяц берётся из тарифа (`priceamount`, иначе `amount`, иначе 8).

## Флаги

| Флаг | Когда ставится |
|---|---|
| Новичок с ДД.ММ: ожидается X, начислено Y | старт в этом месяце, начисление не совпадает с расчётом |
| Первый месяц: было начислено X, ожидалось Y | старт в прошлом месяце, начисление прошлого месяца неверное |
| Похоже, начисления первого и второго месяца перепутаны | в первом месяце полная сумма, во втором неполная |
| Есть посещения, нет начисления | спортсмен ходил (не только на пробное), а начисления нет |
| Оплата без начисления в этом месяце | платёж есть, начисления за месяц нет (предоплата?) |
| Начисление без посещений | начислено, а посещений в месяце нет |
| Несколько начислений за месяц | у спортсмена больше одного начисления |
| Спортсмен в архиве, но есть начисление | статус «Архив» |
| Не оплачено / Недоплата / Переплата | сравнение начисления с платежами, привязанными к нему |
| Скидка — проверить сумму | у спортсмена есть скидка; со скидкой сумма пока не проверяется |
| Только пробное занятие | после пробного посещений не было |

## Открытые вопросы

- Формула колонки «Отклонение». Сейчас она считается как «Сумма по договору − Выручка».
- «Сумма по договору» сейчас равна цене тарифа. Индивидуальные суммы и скидки пока не учитываются.
- Правила для тех, кто ушёл в середине месяца, вернулся после перерыва или перешёл в другую группу.
